# Data

PatternBloom trains and evaluates on multi-hop QA datasets shared between
HotpotQA and 2WikiMultiHopQA. The 14K balanced training corpus and the
hypergraph index over the shared Wikipedia chunks are built locally by the
scripts in `scripts/` and stored in this directory.

## Layout

```
data/
├── README.md                  # this file
├── example_gpm.json           # reference Graph Pattern Memory for inspection
├── processed/                 # generated by scripts/01_prepare_data.sh
│   ├── train.parquet          # 14K balanced (7K HotpotQA + 7K 2WikiMultiHopQA)
│   └── hotpotqa_test.parquet  # 1K HotpotQA test slice
├── hypergraph/                # generated by scripts/02_build_hypergraph.sh
│   ├── chunks.jsonl
│   ├── hyperedges.jsonl
│   ├── embeddings.npy
│   └── faiss.index
└── gpm/                       # generated by scripts/05_distill_gpm.sh
    └── memory.json            # type-abstracted reasoning skeletons
```

## Raw datasets

`scripts/01_prepare_data.sh` downloads the HotpotQA and 2WikiMultiHopQA
splits from a public dataset collection. The splits are cached under
`HF_DATASETS_CACHE` (set to a path with at least 5 GB free). The script
then samples queries from each split, concatenates and shuffles them to
produce the 14K balanced training corpus. The HotpotQA test slice is
sampled with a fixed seed to match the protocol used in the paper.

## Hypergraph index

`scripts/02_build_hypergraph.sh` extracts n-ary hyperedges from the
shared Wikipedia corpus by prompting a language-model extractor over each
chunk, then embeds each hyperedge with `BAAI/bge-large-en-v1.5` and
indexes the embeddings with FAISS. The default extractor is
`Qwen/Qwen2.5-7B-Instruct` served by a local vLLM endpoint; the prompt and
endpoint are configurable in `configs/hypergraph.yaml`.

Building the index over the full Wikipedia corpus takes approximately two
to four hours on a single H100 and produces an artifact of roughly 8 GB
on disk.

## Graph Pattern Memory

`data/gpm/memory.json` is produced by `scripts/05_distill_gpm.sh` after
Stage I training has completed. The memory typically contains 20 to 40
type-abstracted reasoning skeletons distilled from high-IDR trajectories
on the training set. The default merge similarity threshold is 0.85.

`data/example_gpm.json` is a reference memory for inspection; it shows the
JSON schema and gives a concrete example of the kind of skeletons that
emerge after Stage I. It is not used during training or evaluation.
